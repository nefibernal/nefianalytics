# Third-party components

The application files in this fresh build were written anew. These third-party dependencies are bundled locally and retain their licenses:

- Tableau Extensions API, official `lib/tableau.extensions.1.latest.js` snapshot. Source: https://github.com/tableau/extensions-api. License: assets/Tableau-LICENSE.txt.
- jsPDF 3.0.3. Source: https://github.com/parallax/jsPDF. License: assets/jsPDF-LICENSE.txt. Embedded library notices remain intact.
- jsPDF-AutoTable 5.0.2. Source: https://github.com/simonbengtsson/jsPDF-AutoTable. License: assets/AutoTable-LICENSE.txt.
- DejaVu Sans. Source: https://dejavu-fonts.github.io/. License: assets/Font-LICENSE.txt. Base64 font data is in assets/font.js and is subset into PDFs.

The control `<input type="color">` provides the native picker; no Stretch source code is included.
