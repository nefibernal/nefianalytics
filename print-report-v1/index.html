A dashboard extension for Tableau Cloud

Turn your Tableau tables into readable PDF reports.

Give dashboard viewers a simple PDF download button. Configure the report once, then export worksheet data with grouping, subtotals, and repeated page headers.

Configure the report for your table.

Choose and arrange columns

Select which columns to include, change their order, and set number formatting for numeric fields.

Group related rows

Choose grouping columns in order. Repeated labels are suppressed within each group and repeated on continued pages.

Add subtotals

Configure Sum, Average, Minimum, or Maximum calculations. Subtotals are calculated from the exported report rows.

Export paginated PDFs

Choose portrait or landscape. Reports include repeated column headers, page numbers, and a creation timestamp.

How it works

The extension reads the selected worksheet’s current summary data and creates a PDF in the viewer’s browser. It uses its own report layout rather than Tableau’s native PDF export.

The export follows the worksheet’s filters and adapts when hierarchy levels are expanded or collapsed, while retaining the author’s saved PDF settings.

Report data is not uploaded to GitHub or an external PDF-conversion service.

Set up once. Download from the dashboard.

  1. Download the installation file.
    Save the .trex file using the download button on this page.
  2. Add the extension to your dashboard.
    In Tableau desktop, add an Extension object, choose Access Local Extensions, and select the downloaded .trex file.
  3. Configure and save.
    Select the worksheet, PDF columns, grouping, optional subtotals, background color for the dashboard object, and report orientation. Save the configuration and publish your workbook.
  4. Download a report.
    Viewers sets the desired filter (if applicable) and click the Download PDF icon. File is saved and ready to print, quick and simple!

Before you install

Does my Tableau administrator need to approve it?

For Tableau Cloud, a site administrator must allow this network-enabled extension. The hosted extension URL is https://nefibernal.github.io/nefianalytics/print-report-v1/extension.html. Your organization’s extension policies apply.

Does it automatically open or print the PDF?

It requests a PDF download. Save-location prompts and whether the downloaded PDF opens automatically depend on your browser and environment settings. You can print the saved PDF from your PDF viewer.

Will it reproduce every Tableau layout exactly?

No. The extension creates a configurable tabular report from worksheet summary data. Test your worksheet’s formatting, hierarchy, and calculations before sharing it with viewers.
