Set up PDF report

PDF columns

Check columns to include them. Use the arrows to change their order.

Number formatting is available only for numeric columns. Text and dates are unchanged. Percentage formatting uses fractional values (0.125 becomes 12.5%).

Subtotals

Choose a calculation for each numeric column to subtotal.

Rows are grouped in first-seen order, with a subtotal after each group. Calculations use report rows and skip missing numbers. Average is an unweighted average. Subtotals use the column's number format; automatic format shows up to six decimals.
