Set up PDF report

PDF columns

Check columns to include them. Use the arrows to change their order. Collapsed hierarchy columns are skipped at download time and return when expanded. Grouping and subtotals adapt to the currently available columns.

Number formatting is available only for numeric columns. Text and dates are unchanged. Percentage formatting uses fractional values (0.125 becomes 12.5%).

Grouping columns

Add grouping columns in order, from outermost to innermost. For example: Scan Status, then User Name. Labels appear once within each group and repeat on continued pages. With no grouping columns, every row shows all values.

PDF column order is controlled separately above. First-column values and subtotal rows print in bold. The report creation date and time is always shown under the title.

Subtotals

Choose a calculation for each numeric column to subtotal.

A subtotal is added after each selected group within its parent groups. Group order follows the first appearance in the table. Calculations use report rows and skip missing numbers. Average is an unweighted average. Subtotals use the column's number format; automatic format shows up to six decimals.
