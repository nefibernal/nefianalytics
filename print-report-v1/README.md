# PDF Report Download — application build 1.0.4

The configured dashboard button is now a download icon with the tooltip **Download report**. Clicking it retrieves the selected worksheet's filtered rows, creates the paginated PDF, and immediately requests a download. There is no PDF preview window and no scripted print call. Existing table, background, orientation, and Include filters settings are retained.

This build corrects hierarchical filter descriptions, restricts setup saving to authors, locks controls while saving, and updates jsPDF/AutoTable. Setup still has the same four options. See REVIEW_FIXES.md for the finding-by-finding record.

## Update the existing extension

1. Extract this ZIP.
2. In https://github.com/nefibernal/nefianalytics use **Add file > Upload files**. Upload the extracted **print-report-v1** folder to the same location, replacing matching files. Do not nest it inside another folder with that name.
3. Commit and wait for GitHub Pages deployment.
4. Confirm https://nefibernal.github.io/nefianalytics/print-report-v1/ shows build **1.0.4**.
5. In Tableau, select the existing extension's menu > **Reload**. Its icon should become a download arrow. Configure should show build **1.0.4**.
6. Click the download icon. If Tableau/browser presents a Save As dialog, select the location. Otherwise check the configured downloads folder. Open the saved PDF if it does not open automatically.

**Do not remove and re-add the extension for this update.** The extension ID, settings key, permissions, and manifest filename stay unchanged. The included `Nefi_Print_Report_1_0_0.trex` now declares version 1.0.4, displays PDF Report Download, and uses the entry URL with `?build=1.0.4`. Existing objects may still reference an older query string; the hosted entry path is the same and serves the updated application. The website runtime is 1.0.4. If the previous runtime persists, wait for deployment/cache refresh and reload again.

## Download behavior and limits

Tableau's public Extensions API does not expose a native download/save/open operation for a PDF generated by an extension. This build uses an in-memory PDF Blob and a standard HTML download link. This requests the host's normal download handling; it does not bypass host restrictions or guarantee that Tableau Desktop will accept Blob downloads. Native Desktop behavior must be verified in the user's environment.

The extension cannot force a save-location prompt, detect whether the user saved or canceled, retrieve a local save path, or open a saved file in the default desktop PDF application. Save location and automatic opening depend on Tableau or browser settings. If downloads are silently blocked, the extension cannot detect that outcome. It displays **PDF download requested**, not **Saved** or **Opened**. No report data is uploaded to a server.

## New installation

1. Upload the complete print-report-v1 folder to the repository root.
2. Add the included `Nefi_Print_Report_1_0_0.trex` using Tableau's Extension object.
3. Accept Tableau's third-party prompt. Setup opens after successful initialization in authoring mode. Unconfigured viewers are told to contact the dashboard author.
4. In authoring mode, choose the table, background color, Portrait/Landscape, and Include filters toggle; click Save. Controls lock until saving completes.
5. Save/publish the workbook to retain settings. Cancel leaves the gear available to reopen setup.

## Report scope

- All filtered summary-data reader pages are requested; no added fixed row cutoff. Platform and memory limits can still cause errors.
- Flat tables follow the Tableau API's row/column output. This does not reproduce pivoted worksheet layout exactly.
- The worksheet name is the report heading. The supported API does not expose the complete displayed title or resolved `<Data Update Time>`; no refresh-time feature is added.
- Include filters defaults On and controls only the filter-summary section. Turning it Off does not change filtered table values.
- Saved orientation is honored, Letter paper is used, table headers repeat, and wide tables continue horizontally with the first column repeated.
- The native color picker remains unchanged; eyedropper support depends on the environment.
- All runtime libraries are bundled. Configuration is saved through Tableau settings; report values are not saved to browser storage.
- The previously reported removal crash remains unresolved and is outside this update.
