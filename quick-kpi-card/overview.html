Quick KPI Card for Tableau

Build polished KPI cards in seconds.

Bring your metrics, labels, header, and optional image together in one Tableau card. Add it to your dashboard in a few clicks and spend less time aligning floating objects or arranging layout containers.

Download Tableau extension Setup instructions

Make the card fit your dashboard

Lead with the number that matters

Use the 1st Metric on its own or add a 2nd Metric for context, like new accounts alongside deposit growth.

Control the visual hierarchy

Choose fonts, sizes, colors, and alignment for your metrics and labels. Move the second metric’s label above, below, left, or right of its value.

Add an image where it helps

Place an optional logo or icon on either side of the primary metric. The metric uses the full row when there’s no image.

Use a title or a slim accent bar

Customize the header’s text and background. For a slim accent bar, set the height to 8 px and match the text color to the background.

Create your first card

Download the .trex file
  1. In a Tableau worksheet, open the Marks dropdown, select Add Extension, then choose Access Local Extensions and open the downloaded .trex file.
  2. Drag a measure to 1st Metric. Add a 2nd Metric if you want one.
  3. Open Format Extension to style the card, then add the worksheet to your dashboard.
Publishing to Tableau Server or Cloud

Ask your Tableau site admin to add the extension URL to the safe list under Settings → Extensions.
